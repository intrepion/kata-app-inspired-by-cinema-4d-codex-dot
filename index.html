ORBITWEAVE / A SMALL STUDIO FOR BIG IDEASA little motion goes a long way.

Make a little motion.

Choose a layout and primitive. Each effector transforms the same live set of clones. Radial falloff softens the effect toward the outside.

Space: play/pause. Ctrl/⌘ Z: undo. Ctrl/⌘ Shift Z: redo. Ctrl/⌘ S: save. Drag the viewport to orbit, or focus it and use arrow keys. Use + / − to zoom.

This original Cinema 4D-inspired kata uses a lightweight 3D-to-2D projection. It has no polygon modeling, ray tracing, physics, native C4D files, or video export. PNG exports use the current view at 1800 × 1200.

Autosave is best-effort and local to this browser. Download projects for durable backups.
